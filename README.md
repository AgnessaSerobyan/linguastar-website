# LinguaStar Landing Page

Standalone React and Vite project for the LinguaStar landing page redesign.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production client build is written to `dist/client`.

## Publish with GitHub Pages

1. Create a GitHub repository from this folder and push the `main` branch.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. The included workflow builds and deploys the site on every push to `main`.

For a repository named `linguastar-website`, the public address is
`https://YOUR-USERNAME.github.io/linguastar-website/`. The workflow detects the
repository name and sets the correct asset path automatically.
